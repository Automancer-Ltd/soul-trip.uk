# `soul-trip.uk` Ubiquitous Language Glossary

Every term below maps directly to the canonical domain vocabulary in [`VISION.md`](VISION.md), [`SPEC.md`](SPEC.md), and [`scripts/`](scripts/).

| Term / Identifier | Code & Config Binding | Definition |
|---|---|---|
| **Served Path** (`isServedPath`, `listIntendedServedFiles`) | [`scripts/site-contract-lib.mjs`](scripts/site-contract-lib.mjs) | Any git-tracked path where no segment begins with `.` or `_`, other than the repo-only `scripts/`, `docs/`, `AGENTS.md`, `SPEC.md` and `GLOSSARY.md`. `scripts/stage-site.mjs` copies exactly these into `_site/` for GitHub Pages, and they are hashed into `site-manifest.json` unless excluded. |
| **Deploy Fingerprint Exclusion** (`FINGERPRINT_EXCLUDED_FILES`, `isFingerprintExcluded`) | [`scripts/site-contract-lib.mjs`](scripts/site-contract-lib.mjs) | Exact-name exclusion list (`["CHANGELOG.md", "VISION.md"]`) for files whose post-seal or authority-0 commits must not invalidate `site-manifest.json`. |
| **Site Manifest** (`MANIFEST_NAME`, `buildManifest`) | [`site-manifest.json`](site-manifest.json), [`scripts/generate-manifest.mjs`](scripts/generate-manifest.mjs), [`scripts/check-manifest.mjs`](scripts/check-manifest.mjs) | Canonical deterministic JSON mapping every non-excluded served path to its `sha256` digest, verified pre-deploy by `check-manifest.mjs` and post-deploy by `verify-production.mjs`. |
| **Static Site Contract (`C1`–`C9`)** (`CHECK_LABELS`, `CONTRAST_PAIRS`, `FORMSPREE_HOSTS`, `REQUIRED_JS_SNIPPETS`) | [`scripts/check-site.mjs`](scripts/check-site.mjs) | The nine static assertions checking internal links/fragments (`C1`), image alts (`C2`), Formspree enquiry wiring and honeypot parity (`C3`), Sentry loader attributes (`C4`), WCAG AA colour contrast (`C5`), favicon/robots/sitemap (`C6`), footer landmark/heading accessibility (`C7`), `#privacy` disclosure links (`C8`), and the `404.html` not-found page (`C9`). |
| **Sentry SRI & Privacy Verifier** (`PINNED_SDK_URL`, `SENTRY_SDK_FIXTURE`) | [`scripts/check-sentry-integration.mjs`](scripts/check-sentry-integration.mjs), [`assets/js/sentry-init.js`](assets/js/sentry-init.js) | End-to-end check proving that `<script id="sentry-sdk">` points to `PINNED_SDK_URL`, its `sha384` SRI matches the served bundle bytes, and `sentry-init.js` scrubs PII (`sendDefaultPii: false`, `beforeSend`). |
| **Production Verifier** (`verifyOrigin`, `runProveMode`) | [`scripts/verify-production.mjs`](scripts/verify-production.mjs) | Post-deploy gate that fetches `https://soul-trip.uk/site-manifest.json`, requires byte identity with the local manifest, and verifies the live SHA-256 of every listed asset. |
| **Negative-Control Suite** (`makeCopy`, `detachCopyRepo`, `SABOTAGES`) | [`scripts/test-negative-controls.mjs`](scripts/test-negative-controls.mjs) | Hostile-mutation test suite proving every checker fails for the expected reason on sabotaged copies of the site. |
| **Config Check** | [`scripts/check-meta.mjs`](scripts/check-meta.mjs) | Fails when `deploy.json` stops pointing at the Pages deployment or `.release-notes.json` stops declaring `deployTrigger: push` (the release-notes lane would skip the repo). |
| **Enquiry** (`#enquiry-form`, `showEnquirySuccess`) | [`index.html`](index.html), [`assets/js/main.js`](assets/js/main.js), driven by [`drive-enquiry.sh`](.agents/skills/verify-soul-trip-uk/scripts/drive-enquiry.sh) | A visitor's message to the company, POSTed to the live Formspree form. The product of the site (`VISION.md`): `C3` pins its wiring and the browser walk proves a submit reaches Formspree and shows the success panel. |
